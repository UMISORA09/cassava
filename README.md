# 🏠 Cassava - Nền tảng quản lý và tìm kiếm phòng trọ

**Cassava** là một website hiện đại để quản lý, tìm kiếm và liên hệ về phòng trọ.

## 🎯 Tính năng chính

- 📋 Danh sách phòng trọ với search & filter
- 👤 Hệ thống đăng ký/đăng nhập
- 📝 Đăng tin phòng trọ (cho chủ nhà)
- 🔍 Tìm kiếm nâng cao (giá, diện tích, vị trí, etc.)
- ⭐ Rating & Review phòng trọ
- 💬 Hệ thống liên hệ/yêu cầu xem phòng
- 📱 Responsive design (mobile-friendly)
- 🔐 Admin panel quản lý
- 🗺️ Vị trí trên bản đồ

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** PHP 7.4+
- **Database:** MySQL 5.7+
- **Server:** Apache/Nginx
